Lectura con IA (opcional)

Por defecto el ticket se lee con un OCR que funciona dentro de tu móvil o navegador. Si pones la clave de API de una IA, la foto se envía a ese servicio, que lee mejor facturas y fotos difíciles. Se paga por uso (céntimos por ticket) y la clave solo se guarda en este dispositivo.
